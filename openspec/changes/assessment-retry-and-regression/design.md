# Design

## Context

评估子图可独立调用。历史已保存公开快照，补跑需要独立保存冻结输入及当前中间结果。现有评测中心已有人工确认及冻结回放。

## Decisions

- 独立保存私有重试上下文，公开快照只增加重试选项与修订号。
- 通过现有评分、审查、聚合和报告函数执行补跑。报告命题审查失败时仅重查目标命题。评分变化时重算关联候选人的一致性与摘要，再按原规则聚合。
- 校验错误以白名单原因码展示。较大审查批次在可重试错误后分成更小请求，保留已取得的合法结果。
- 重试结果以修订号检查并原子写回。当重试执行中出现服务级错误时保留上一次报告。
- 离线流程随提交自动执行，显式真实模型回放可使用固定人工标签并比较两份同输入、同标签的报告。另用小型虚构材料测试切块后的证据召回。

## Risks / Trade-offs

重试上下文包含已取证的原文，使用运行历史既有访问边界和数据保留规则。旧报告继续可读。正式质量仍依赖实际完成的人工确认。
