# Spec Delta

## ADDED Requirements

### Requirement: 人工基准可确认和自动回归

系统 SHALL 在评测界面展示虚构案例的命题、引用原文以及候选标签，供人工核对提交。正式质量只使用已确认且与冻结输入匹配的标签。

#### Scenario: 例行代码变更
- **WHEN** GitHub 检查执行默认回归
- **THEN** 离线回放和证据召回样例无需外部模型即可运行，留存指标、失败数及耗时

#### Scenario: 指定真实模型对照
- **WHEN** 显式执行同一冻结输入和人工基准的两份对照
- **THEN** 系统报告匹配样本、失败、耗时及可比较的质量指标，并明确缺失确认或基准不一致
