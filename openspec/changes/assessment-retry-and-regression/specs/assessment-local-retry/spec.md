# Spec Delta

## ADDED Requirements

### Requirement: 报告可局部重试技术失败

系统 SHALL 标识失败的候选人、维度和公开原因，并提供针对仍可重试的事项的操作。重试 SHALL 复用当轮冻结证据以及无须重新确认的成功结果，重新生成受影响的结果和聚合值。

#### Scenario: 评分模型输出无法通过校验
- **WHEN** 某维度评分发生技术错误且已有冻结证据
- **THEN** 用户可补跑该维度并查看写入历史的报告修订，其他成功评分继续复用

#### Scenario: 审查批次出现协议错误
- **WHEN** 一批审查无法为全部命题提供合法结果
- **THEN** 系统保留合法结果，对可重试失败项使用规模更小的请求并执行有限重试

#### Scenario: 并发请求试图覆盖当前报告
- **WHEN** 客户端提交过期修订号或同轮重试正在执行
- **THEN** 系统拒绝覆盖，并保留最新报告
